\# hash-verify-cli



A minimal command-line tool to verify SHA256 hashes against a directory of files.



This is intended to validate evidence bundles generated by tools such as

\[`incident-evidence-packager`](https://github.com/maryamoah/incident-evidence-packager).



\## What it does

\- Reads a standard `hashes.sha256` file

\- Recomputes SHA256 hashes

\- Reports OK, BAD, or MISSING files

\- Returns a meaningful exit code



\## Usage



```bash

python verify\_hashes.py <base\_dir> <hashes.sha256>
